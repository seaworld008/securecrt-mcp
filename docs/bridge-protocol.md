# Bridge protocol 2

Private local NDJSON over TCP, explicitly `127.0.0.1`, default port 27855. One request and one response per connection, maximum frame 262144 bytes. Authentication uses a per-install random token; the adapter compares it with `hmac.compare_digest`. Requests carry an absolute Unix millisecond deadline. Expired/oversized/malformed requests do not dispatch. This is local transport, not TLS or a same-user sandbox.

```json
{"protocol_version":2,"id":"uuid","token":"local-secret","deadline_ms":1789891000000,"method":"ping","params":{}}
```

```json
{"protocol_version":2,"bridge_instance":"uuid","id":"uuid","ok":true,"result":{},"error":null}
```

Methods: `ping`, `list_sessions`, `read_screen`, `focus_session`, `begin`, `poll`, `end`, `interrupt`, `acknowledge_idle`, `send_text`. Their adapter signatures are the canonical parameter contract.

`begin` requires an opaque session lease, screen token, expected input prompt, capture ID, bounded runtime and final text already authorized/generated by Rust. `poll` captures bounded data with match/expiry/incomplete metadata. `end` releases native screen settings; a nonconfirmed end creates an unresolved interlock. `interrupt` must match the current tracked capture, never a guessed tab position. All native calls execute on the script thread, not a Python network worker.

Wire UUIDs correlate requests but do not implement remote exactly-once semantics. There is no retry in BridgeClient. If a response is lost after sending, preserve unknown state and inspect rather than creating another command. The adapter watchdog releases abandoned capture settings but never kills remote work.

A protocol mismatch is an error. Run CLI `upgrade`, cancel the old script, and start the upgraded copy. Do not silently downgrade to protocol 1.
