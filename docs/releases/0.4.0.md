# securecrt-mcp 0.4.0

## Stable release

This release keeps the existing SecureCRT Bridge and all `securecrt_*` MCP
tools compatible, and adds an explicit unified connector API.

### Included

- Persistent OpenSSH command sessions using the system `ssh` client.
- Persistent OpenSSH PTY sessions with incremental cursor reads, resize,
  explicit raw input, interrupt and close operations.
- Bounded output, UTF-8 previews with binary `base64` fallback, gap reporting,
  unknown/no-replay semantics and operation-id deduplication.
- Connector timing, native-read, retained-byte and throughput metrics.
- Adaptive SecureCRT native output draining for continuous large output while
  retaining prompt readiness and context-change safety.
- Chinese and English connector documentation and corrected Codex tool presets.

### Verification

- Rust unit tests: 20 passed.
- Python regression tests: 75 passed.
- Release build, Clippy with `-D warnings`, MCP stdio and packaging smoke tests passed.
- Windows x64 real SecureCRT 9.0.0 / embedded Python 3.8.10 acceptance passed.
- Read-only live acceptance covered SecureCRT session reuse, host diagnostics,
  MySQL 8.0.35 metadata queries, 461MB log inventory and multi-page bounded
  large-log reads. A timed-out large read entered unresolved state and was
  recovered only through explicit screen inspection and idle acknowledgement.

### Boundaries

OpenSSH is opt-in and uses the caller's OpenSSH configuration, Agent,
ProxyJump and known_hosts. MCP does not store passwords or implement a second
approval system. Real remote OpenSSH throughput depends on the available
client configuration and test host; no automatic fallback between backends is
performed. SecureCRT screen APIs remain sampled and are not advertised as a
native PTY.
