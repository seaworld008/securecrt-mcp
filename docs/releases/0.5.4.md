# securecrt-mcp 0.5.4

Windows 用户现在可以按包内 `START-HERE.md` 完成安装、加载脚本、接入客户端与检查。无需自行编译或安装 Python、Node、Rust。

## 下载与使用

Windows 选择 `securecrt-mcp-0.5.4-x86_64-pc-windows-msvc.zip`，核对本 Release 的 `SHA256SUMS` 后完整解压。Mac 和 Linux 用户选择对应架构，遵循包内安装说明；本次 Windows `.cmd` 向导不适用于这些平台。

1. Codex 用户双击 `install.cmd`，窗口保留安装结果和脚本路径。仅使用 Claude/其他 MCP 客户端时，改用 `initialize-only.cmd`，按包内客户端指南注册。
2. 双击 `show-paths.cmd`，在 SecureCRT 的“脚本 → 运行”或 Xshell 的“工具 → 脚本 → 运行脚本”中选择对应入口。
3. 重新加载 AI 客户端，用 `check-securecrt.cmd` / `check-xshell.cmd` 检查自己的终端。
4. 明确指定空闲测试标签并授权一次无害命令，核对实际返回；完整操作和排障见包内中英文快速指南。

## 改进

- 安装成功后窗口不会立即消失，错误不会被后续步骤掩盖。
- 安装、路径查看、两个终端的在线检查、其他客户端初始化各有明确入口。
- 快速指南明确安装一次、关闭终端后重新加载脚本，以及自定义目录必须一致的要求。
- 包内包含配套二进制、自包含 Windows 脚本和完整文档；保留已有配置、令牌、审批和 SSH 登录。
- 新增隔离 Windows 环境中的实际 CMD 安装/重复安装及失败路径回归，校验中文和空格目录、配置保留、桥接未启动、配置错误及缺失 EXE。
- 修正中文 README 镜像不一致。执行引擎行为与协议没有变更。
- 主分支检查发现 Unix 超时测试存在解释器冷启动竞争；增加夹具就绪握手，保留原 200 毫秒捕获期限和断言，不通过放宽超时或重试掩盖失败。

## 验证范围 / Validation scope

本次优化前，0.5.3 基线 `9608231757ef3227b4f76dd95603abf41663f192` 在 Windows 上完成了 SecureCRT 9.6.0 x64 build 3472 和 Xshell 8（原生报告 8.0.0.26，x86）的真实 UI 脚本加载、会话发现、一次无害 printf、输出捕获、`completed`/退出码 0 和同时运行检查。在线诊断通过。0.5.4 改动聚焦包入口、文档和测试；桥接只同步版本标识。此基线结果不等于最终 Release 二进制的完整桌面验收。

发布流水线对所选精确源码执行 Rust/Node 检查并构建四个目标；Windows 回归实际调用包内 CMD，在隔离目录验证安装与配置保留。最终发布资产由 CI 生成并提供 SHA-256。

This release improves Windows onboarding and package checks without changing terminal execution behavior. The live desktop evidence above belongs to the stated 0.5.3 baseline. It does not certify the complete 0.5.4 desktop matrix, interruption/reconnection, multi-tab isolation or AI client approval rejection. No new macOS/Linux desktop run is claimed; Intel macOS remains a cross-build on the selected macOS runner. Xshell runtime diagnostics may classify support as tier_2 without an exact tier_1 certificate.
