# securecrt-mcp 0.4.1

## Stable patch release

This patch fixes SecureCRT Bridge startup when SecureCRT has no active or
connected server tabs. The local listener now starts independently of the
session list. `connector_list` returns an empty
session list until a server tab is opened, then discover the connected tab on
the next request.

The adapter also treats unavailable tab-bound dialog and sleep APIs as
non-fatal during startup, which avoids aborting the listener before the first
session exists. Existing prompt, context, unknown-result and no-replay safety
semantics are unchanged.

Validation includes the zero-tab startup regression, all Rust and Python test
suites, strict Clippy, repository validation, package smoke tests, and live
SecureCRT 0.4.1 bridge lifecycle checks.
