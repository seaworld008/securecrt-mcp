# 0.3.0-preview.2 — 已确认完成后的提示符重绘修复

本预览版集中修复 `0.3.0-preview.1` 在同一 attachment 连续执行命令、或者 batch 紧接着执行下一条时的 `context_changed` 误拒绝。Bridge 协议仍为 2，不修改客户端审批、命令策略或 shared/exclusive/observe 的语义。

## 根因与范围

POSIX 结束标记表示命令已完成，不表示 SecureCRT 已经重绘好下一次输入行。旧 guard 对原提示符已经显示、光标尚未恢复的状态立即拒绝；对第一次碰巧匹配的采样又过早清除了等待状态。batch 连续执行会放大这个时序窗口。

现在只在原 capture 的完成标记由 Rust 确认且原生设置恢复成功后，允许下一次发送前进行只读 readiness/rebase：最多 500ms、受请求剩余 deadline 约束、约 10ms 采样间隔，要求原提示符、光标列和终端宽度连续两次匹配。仅此阶段允许上一条命令滚屏导致的行号变化。正常已稳定的提示符通常只增加一个采样间隔，不固定等待满 500ms。

半行输入、密码/passphrase、pager、REPL、编辑器、不同提示符、其他 capture 的标记、越过输入边界的光标和终端宽度变化继续拒绝发送。未知、超时、未决状态或没有本次 marker 证据时不进入恢复路径。没有自动重发、自动 Ctrl+C、自动确认空闲、新 SSH 连接或新审批系统。

`context_changed` 现在保留为独立错误码，并附带原终端检查建议。readiness 耗尽是下一条命令未发送，不是把上一条已完成命令重新执行。

## 测试与交付

只采用 `fix/prompt-readiness-rebase` 的实现；未叠加另一个分支对普通校验路径和永久失效语义的改动。临时补丁及应用工作流已从交付树移除。

保留原有测试，并加入一份确定性重绘单元测试套件和一份编译后 MCP/TCP/Adapter 冒烟测试：连续三条命令、三条 batch 的独立输出/退出码/审计、第二条不确定时停止、两个 Tab 隔离、超时后不重放。测试使用模拟原生屏幕，不连接业务 SSH。

发布门槛包含 Windows/macOS/Linux CI、Python 3.8/3.12 兼容性、严格 Clippy、pytest、编译后回归和四个目标的 Release 编译。macOS Intel 包为交叉编译；CI 不能代替真实 SecureCRT 桌面验收。历史 benchmark JSON 保持原样，不改名冒充本版实测。

## 下载与升级

Assets 提供 Windows x86_64、Linux x86_64、macOS Apple Silicon、macOS Intel ZIP，以及所有 ZIP 的 `SHA256SUMS`。二进制内嵌对应版本的 Adapter；不用另找 Python 脚本版本，但运行 SecureCRT 脚本仍需兼容的 Python 环境。

先检查活动或未决命令，停止旧 MCP/daemon 和 SecureCRT Bridge 脚本；已登录 SSH Tab 保持打开。解压对应 ZIP、检查 SHA-256 后，在包目录执行：

```powershell
.\securecrt-mcp.exe --version
.\securecrt-mcp.exe upgrade
.\securecrt-mcp.exe doctor --offline
.\securecrt-mcp.exe paths
```

在 SecureCRT 中重新运行 `paths` 输出的已安装脚本，然后执行：

```powershell
.\securecrt-mcp.exe doctor
.\securecrt-mcp.exe doctor --latency
```

确认 Agent 启动的是新二进制的实际路径。`upgrade` 保留原策略和 Token，不需要 `init --force`。旧 attachment 属于旧进程，重启后为原 Tab 建立一次新 attachment；随后测试连续命令，不要每条命令重新 attach。

源码构建可使用：

```sh
cargo fmt --all -- --check
cargo test --locked
python -m pytest -q tests
cargo build --locked --release --target-dir target-latest-test
python tests/prompt_readiness_smoke.py target-latest-test/release/securecrt-mcp
```

Windows 最后一条使用 `.exe` 后缀。

## 保留的边界

shared 输入检测仍然是采样，不保证发现采样间所有人工输入；exclusive 仍不是原生键盘锁，observe 仍不允许写入。不要在同一 Shell 同时人工输入和自动执行。

500ms 限制主动等待预算，不是 SecureCRT 原生调用或桌面调度的硬实时保证。本版不声称拥有原生 PTY，也不宣称绝对等价于 SSH 直连。请继续在真实 SecureCRT/Codex/Claude 环境验收。
