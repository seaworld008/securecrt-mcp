# securecrt-mcp 0.5.0

## Unified connector release

This release makes `connector_*` the single public MCP namespace. The caller
selects `securecrt`, `xshell`, or `openssh` with the `backend` field when it
opens a session. The old `securecrt_*` MCP tools are removed from the final
surface during this development phase.

Xshell is now supported through an authenticated file-IPC Script Bridge. The
Rust `init` and `upgrade` commands install the latest `securecrt-mcp-xshell.py`
directly into Xshell's standard Scripts directory, while the token and IPC
directory remain in the MCP private directory. Every Xshell process registers
an isolated instance; the Rust side aggregates live instances, discovers named
`.xsh` sessions by filename, and routes attachments through the originating
process.

Both desktop bridges reject an explicit prompt mismatch before sending native
input. This preserves the no-replay and fail-closed behavior when a tab changes
between inspection and execution.

The Xshell bridge keeps startup notices outside the host's modal dialog path,
uses a one-millisecond host-owned wait for responsive cancellation, writes bounded
per-instance lifecycle logs, and cleans up silently when the operator cancels the
script.

Validation includes Rust format, check, Clippy, unit tests, Python adapter
tests, MCP and UX smoke tests, performance and fault-injection smoke tests, and
package validation. The release gate still requires live SecureCRT and Xshell
acceptance after each desktop client reloads the installed 0.5.0 script.
