# securecrt-mcp 0.5.3

## Highlights

- Make Simplified Chinese the primary repository entry while retaining complete English alternatives for installation, daily use, Claude, and maintenance.
- Add practical Agent setup prompts, a documentation map, cross-Agent repository guidance, and maintenance/release boundaries.
- Document current-main installation and distinguish it from the older v0.5.2 archives, which predate the current installer and self-contained Windows entries.
- Preserve existing MCP entries, approvals, policies, tokens, and SSH logins during Codex/Claude setup.
- Harden documentation and package validation, including bilingual navigation, archive documentation membership, CRLF-compatible validation, and Claude CLI argument ordering.

## Validation scope

The source commit passed the four-platform CI matrix: Linux, Windows, macOS, and the Mac native SDK contract. GitHub-rendered Chinese-first navigation, English alternatives, badges, documentation links, and configuration examples were checked separately. This release does not claim a new SecureCRT/Xshell desktop acceptance run; see the support matrix and historical acceptance receipts for exact runtime evidence.
