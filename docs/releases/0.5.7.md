# SecureCRT MCP 0.5.7

Windows bridges now support a normal stop that keeps SSH connections open. Use
`stop-securecrt.cmd` or `stop-xshell.cmd`, confirm that the selected terminal is
idle, and select the displayed instance. Entering `0` cancels without stopping
anything. Active captures, unresolved commands, stale generations and mismatched
adapter identities are refused before any terminal input.

Startup messages now describe the running tool and its connected sessions. The
installer and diagnostics provide platform-specific recovery guidance. Forced
**Script → Cancel** remains a terminal-owned notification; normal stop avoids it.
Bridges predating this capability require one idle cancellation before upgrading.

Consecutive file IPC exchanges keep a bounded 25 ms period of short native waits
after a response. Normal idle waits resume afterward; terminal APIs still run on
the host script thread, with existing ownership, prompt and capture guards.

This release includes the Mac 0.5.6 activation, screen-token, persistent TCP,
OpenSSH policy/audit and portable script-transfer changes. Windows regression
receipts and native SSH comparison are recorded in the
[Windows acceptance report](../acceptance/windows-mac-regression-2026-10-14.md).
Mac desktop evidence remains scoped to its
[tested 0.5.6 source](../acceptance/mac-native-matrix-2026-10-14.md); Mac SDK fixtures
and CI do not replace a new native desktop test of this Windows-focused release.

OpenSSH command sessions now preserve exact command output by removing only
the envelope's separator LF. Empty output, output without a trailing newline,
real blank lines and an exact output-limit body are covered. A real Windows
MCP/OpenSSH run measured 12 ms p50 / 16 ms p95 for 100 warm commands and returned
2,500 Unicode rows in 34 ms, with batch, de-duplication, policy and audit checks.

Desktop SDK waits still constrain native bridge latency. The report retains a
default SecureCRT mixed parallel stress timeout; raw logging passed parallel
full suites and remains opt-in. Prefer it for long concurrent diagnostic output.

The Chinese and English READMEs retain their introduction and architecture diagram,
and reorganize backend selection, installation, daily tools, recovery, measured
performance and contribution guidance. Upgrade guides now prefer normal Windows
stop and reserve native cancellation for older bridges and macOS.

Windows SecureCRT and Xshell diagnostics now validate every online native instance
by default. The optional doctor --instance selector checks only its requested
identity, refuses missing targets and sends no SSH input. Desktop acceptance uses
this scope both before execution and for its final runtime verdict. Mac TCP
diagnostics retain their existing text format.
