# 0.3.0-preview.3 - adaptive SecureCRT prompt readiness

This preview incorporates real SecureCRT desktop feedback from `0.3.0-preview.2`.

## What changed

- Keep the 500 ms prompt-readiness fast path for normal completed commands.
- Extend once to a 1.5 second total budget only when the adapter has observed a safe repaint transition: a blank line, the exact owned completion marker, or the original prompt with a cursor that has not reached its original input boundary.
- Keep rejecting half-typed input, password prompts, pagers, REPLs, editors, changed prompts, resized terminals and unknown command outcomes without sending input.
- Expose `prompt_readiness_extensions` in Bridge metrics so real SecureCRT redraw behavior can be measured instead of guessed.

## Verification

The deterministic MCP/Bridge tests cover slow redraws, two-sample prompt stability, batch stopping, per-tab isolation and no replay after unknown outcomes. Real SecureCRT validation should confirm both fast and slow tabs; the 1.5 second cap is a bounded coordination budget, not a PTY or SSH equivalence guarantee.
